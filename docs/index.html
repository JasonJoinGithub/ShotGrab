输入场景描述，找回电影里的参考帧 · 网页版

点数：—

先花一分钟，把 API 接上

截图库通过 FrameThrower 官方接口搜索影片参考帧，需要你自己的免费账号 token（新账号送 200 点，搜一次花 2 点，不用绑卡）。

  1. 打开 framethrower.ai，用 Google 或邮箱免费注册并登录。
  2. 进 Settings → API，点 + Create token 创建一个 token（只显示一次）。
  3. 把 token 粘贴到下面，点「保存并开始用」。它只保存在你的浏览器里，只在调用 FrameThrower 接口时发给 framethrower.ai，不会发给任何别的地方。

每次搜索花 2 点；点一张帧看详情花 2 点；找相似花 2 点。

其他站也搜搜（免费，不花点）：

FilmGrab · 按片名 Shot.Cafe · 按标签 MovieStillsDB · 按片名/人名

在上面输入片名或描述后，这里自动带上你的查询词（免费，不花点；片名用英文效果最好）。

Flim · 点开手动搜 Frameset · 点开手动搜 ShotDeck · 需付费账号 /refs · 点开手动搜 Ceeniq · 上传剧照做拆解

Flim、Frameset、ShotDeck、/refs 没有可预填的搜索链接，只能点开手动搜；Ceeniq 是拆解工具不是图库。/refs 的官方接口在测试中，开放后可以接进来（等候名单：therefs.org/api）。

摄影术语（点一下，加进查询框）：

粘一段剧本（场景描写、动作段落都行），程序先拆出时间、地点、人物、动作、情绪，再用这些去电影里找最像的场景。匹配帧的提示词可以直接复制，去出场景图、人物图、气氛图。

说明
