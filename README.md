# ShotGrab（截图库）— 本地电影参考帧检索

在你自己的 Mac 上运行的电影参考帧检索工具。输入一段场景描述（中文就行），
它通过 FrameThrower 官方接口帮你找到对应的电影帧，并展示完整的影像信息：
景别、摄影机、灯光、场景、人物、色板、场景描述、摄影笔记，全部按
FrameThrower 详情页的结构呈现，还能一键生成中英文提示词、找相似帧、
存进你自己的收藏库。

## 怎么启动

1. 把整个文件夹放到 Mac 上（比如 `~/截图库` 或桌面，位置随意，
   文件夹里的文件不要拆散）。
2. 双击 `start.command`，会弹出一个终端窗口，服务自动启动，浏览器自动打开
   http://127.0.0.1:8765/ 。
3. 用完后直接关闭那个终端窗口，服务就停了。下次用再双击一次就行。

也可以在终端里手动启动：进到文件夹，然后 `python3 server.py`，
再自己打开浏览器访问 http://127.0.0.1:8765/ 。

要求：Mac 自带的 Python 3 即可，不需要装任何别的软件，不需要 pip 装依赖。

## 先填 API token（只做一次，每个人用自己的免费账号）

搜索走的是 FrameThrower 官方接口，需要你自己的免费账号 token。
新账号送 200 点，搜一次花 2 点，不用绑卡：

1. 打开 https://framethrower.ai/ ，用 Google 或邮箱免费注册并登录。
2. 进 **Settings → API**，点 **+ Create token** 创建一个 token（只显示一次，
   当场复制下来）。
3. 回到截图库页面，把 token 粘贴进去，点「保存并开始用」。

token 只保存在你这台 Mac 的程序目录里（`.token` 文件，只有你本人能读），
不会发给任何别的地方，界面上也不会再显示它。想换 token 或清除，
点右上角「设置」。

## 怎么用

- **搜索**：在搜索框里用中文描述画面，比如“雨夜霓虹街道 逆光 中景”，
  程序会自动把中文摄影术语翻成英文再搜（页面上会显示实际发出的英文查询）。
  也可以直接输英文，或者点下面的术语 chips 拼查询。
  站内搜索有时会漏掉个别帧，没找到想要的就换个说法多搜几遍。
- **其他站也搜搜**：搜索框下面有另外 8 个站的跳转——FilmGrab、MovieStillsDB
  按片名、Shot.Cafe 按标签会自动带上你的查询词（免费，不花点）；Flim、
  Frameset、ShotDeck、/refs、Ceeniq 点开手动搜。
- **剧本找场景**：点「剧本找场景」页签，粘一段剧本，点「拆解场景」会先拆出时间、地点、人物、动作、情绪（免费），再按拆解结果去电影里找最像的场景（每组查询花 2 点，最多 3 组）。匹配帧的提示词可以直接复制，去出场景图、人物图、气氛图。
- **详情**：点一张帧，看完整信息——影片、标签、色板、场景描述、人物、
  摄影笔记、关键词；点「一键复制全部信息」一次拷走所有内容（影片、场景、
  人物、镜头、灯光、色彩、提示词都在里面），也可以只复制英文提示词或
  场景描述；还能找相似帧、点「在原站打开」去 FrameThrower 看原页或下载。
- **收藏**：详情里点「保存到收藏」，可以填项目、标签、备注；
  「我的收藏」页可以按项目和标签筛选，还能一键导出全部中英文提示词
  为 Markdown 文件。
- **点数**：页面右上角显示余额。新账号送 200 点；搜索、看详情、
  找相似各花 2 点；$1 = 1000 点，点数永不过期。余额不足时去
  FrameThrower 官网充值。

## 文件说明

- `server.py` — 本机服务（Python 3 标准库，无任何第三方依赖）
- `index.html` / `app.js` / `style.css` — 界面
- `prompt-template.js` — 提示词模板（按 FrameThrower 官方写法提炼，生成中英文提示词）
- `start.command` — 双击启动脚本
- `.token` — 你的 API token（首次粘贴后自动生成，权限 600；不要发给别人）
- `collection.json` — 你的收藏（首次保存后自动生成；只存文字信息和链接，
  不存图片文件）

## 注意事项

- 缩略图是 FrameThrower 提供的临时链接（约 1 小时过期），收藏里只存链接，
  时间久了图片可能打不开，这是正常的，点「在原站打开」就能看。
  程序不会把剧照下载或复制到你的电脑里。
- 剧照只作参考和提示词研究，分享时请注明影片与原站链接，不要直接发布或商用。
- 服务只监听本机（127.0.0.1），局域网里的其他设备访问不了。
- 每个人用自己的 FrameThrower 账号和 token，点数也是各花各的，不要把
  `.token` 文件发给别人。

## 常见问题

- **双击 start.command 没反应 / 提示“无法打开”**：在 `start.command` 上右键 →
  打开，点「打开」即可（第一次需要这样确认一次）。也可能是文件权限掉了，
  在终端里进到文件夹跑一次 `chmod +x start.command`。
- **页面打不开**：确认终端窗口还开着、最后一行显示“截图库已启动”，
  再刷新浏览器。如果提示端口被占用，先关掉之前启动过的截图库终端窗口。
- **搜不到结果 / 提示 token 无效**：进「设置」重新粘贴一个新 token
  （旧的可能过期或被删了）；也可以到 FrameThrower 的 Settings → API 里确认。
- **提示点数不足**：去 FrameThrower 官网充值，$1 = 1000 点。
